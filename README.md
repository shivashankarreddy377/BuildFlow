# Developer Productivity Platform

A full-stack project and task management application for planning work, tracking
progress, and turning project ideas into actionable tasks. The platform combines
a React web interface with a Spring Boot REST API and account-based authentication.

## Highlights

- **Project management:** Create projects with descriptions, due dates, and
  optional file attachments. Update project status and download attached files.
- **Task tracking:** Organize tasks under projects, add due dates and technology
  labels, and track completion.
- **AI planning:** Submit a project idea to generate task suggestions, then add
  relevant suggestions to a selected project's task list.
- **Progress dashboard:** Review project totals, completion status, recent
  projects, and associated tasks.
- **Search and filters:** Find projects and tasks by text, status, or task
  technology.
- **Account security:** Register and sign in to access account-specific project
  and task data using token-based authentication.

## Technology

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Java, Spring Boot, Spring MVC, Spring Security, Spring Data JPA
- **Data and integrations:** MySQL, JWT, Gemini API, file uploads
- **API documentation:** OpenAPI / Swagger UI

## Using the web app

1. Create an account or sign in.
2. Start on **Dashboard** to review project totals and recent activity.
3. Open **Projects** to create a project. Add its title and description, and
   optionally set a due date or attach a file.
4. Select a project, then open **Tasks** to add and manage its tasks. Update
   project and task statuses as work progresses.
5. Use the search box and filters in **Projects** and **Tasks** to narrow the
   displayed items.
6. Open **AI Task Planner**, enter a project idea, and generate task suggestions.
   Select a project before adding suggestions to its task list.
7. Sign out when you are done.

Keep your sign-in credentials private. Check the selected project before adding
tasks so they are associated with the intended work.
